# Documentos históricos

Estos son el diseño (`specs/`) y los planes de implementación (`plans/`)
con los que se construyó el sistema, en el orden en que se escribieron. Se
conservan como referencia de las decisiones tomadas.

**No describen necesariamente el estado actual:** el código cambió después
de escribirlos. Para saber qué hace el sistema hoy, ver el
[`README.md`](../../README.md) y el [`CHANGELOG.md`](../../CHANGELOG.md).

Algunas direcciones y rutas de los planes se reemplazaron por marcadores
(`<ip-de-pruebas>`, `<repo>`).
